# Simple RAG (Retrieval-Augmented Generation) Implementation
(This README.md file is generated by copilot AI)

This project demonstrates a basic implementation of Retrieval-Augmented Generation (RAG) using MeiliSearch for document retrieval, DashScope for reranking, and DeepSeek for generating answers based on retrieved knowledge. The workflow involves searching a knowledge base, reranking the results, and generating a response to a user query.

## Project Structure

### Python Files
1. **`search.py`**:
   - Handles the entire RAG pipeline.
   - Performs the following steps:
     1. Searches the knowledge base using MeiliSearch.
     2. Reranks the retrieved results using DashScope's `gte-rerank` model.
     3. Generates a response using DeepSeek's API.

## Usage

### Prerequisites
1. Install the required Python libraries:
   ```bash
   pip install meilisearch dashscope requests
   ```
2. Ensure MeiliSearch is running locally and contains an index named `Buddhism`.
3. Replace the placeholder API keys in the script with your actual keys:
   - MeiliSearch API key.
   - DashScope API key.
   - DeepSeek API key.

### Steps to Run

#### 1. Search the Knowledge Base
Run the script with a query to search the knowledge base:
```bash
python search.py <your-question>
```

#### Example:
```bash
python search.py "What is the story of Su Dongpo?"
```

#### Output:
- The script will:
  1. Retrieve relevant documents from MeiliSearch.
  2. Rerank the results using DashScope.
  3. Generate a detailed response using DeepSeek.

#### Sample Output:
```plaintext
DeepSeek回答：Su Dongpo was a famous scholar in the Song Dynasty...
```

### Notes
- The `search.py` script outputs the response incrementally in a streaming fashion.
- Ensure all API keys and services are properly configured before running the script.
